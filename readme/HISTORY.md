## 20.0.1.0.0

- Ported to Odoo 20 (OWL 3, `html_editor`, `ir.access` security, native
  `<chatter/>`).
- Renamed the technical name from `i8_knowledge_management` to
  `cl_knowledge_management`.
- New workspace interface: sidebar tree with favourites, search palette,
  inline editor, "On this page" outline, reading time, coloured tags.
- New version history screen with side-by-side diff, including a comparison
  with the live article.
- Threaded comments, mobile layout and redesigned public share page.
- Fixed: article search crashed, users without a department could see
  department-restricted articles, viewing or liking changed "last edited by",
  and the public page needed the Website app.
- New app icon and store banner.
